# Arcusis Branding

This is the official branding repository of **Arcusis**. It holds the logos, colors and
backgrounds for Arcusis and for the communities and products we run.

> זהו ריפו המיתוג הרשמי של Arcusis. כאן נמצאים הלוגואים, הצבעים והרקעים של Arcusis
> ושל הקהילות והמוצרים שאנחנו מפעילים. לפני שימוש בלוגו קראו את [design.md](design.md).

## What's here

| Folder | Contents |
| --- | --- |
| [`Arcusis/`](Arcusis) | The Arcusis logo (wordmark and symbol) in green, black and white, as SVG and PNG, plus the color palette and the 4K background |
| [`Gaming Israel/`](Gaming%20Israel) | Gaming Israel logos, backgrounds, website and social graphics |
| [`Iron Swords/`](Iron%20Swords) | The Iron Swords (חרבות ברזל) logo |
| [`Modiluxe/`](Modiluxe) | Modiluxe product logo and colors |
| [`design.md`](design.md) | The design language: colors with HEX codes, logo versions and when to use each |

## Usage

The Arcusis name and logo are trademarks of Arcusis. You may use the files in this
repository to refer to Arcusis, our communities and our products, for example in press,
partner pages and event material, as long as you follow [design.md](design.md) and do not
alter the logos. See [LICENSE.md](LICENSE.md) for the full terms.

Questions about brand use: open an issue in this repository or contact us through
[arcusis.com](https://arcusis.com).
